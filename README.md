An open-source, zero-lag standalone dual-screen progression tracker and quest checklist built for console and PC gaming.

Designed to run on your **second monitor, iPad, tablet, or smartphone (PWA fullscreen mode)** while playing PlayStation 5 or Xbox Series X/S.

---

## ⚡ What's in this Free Starter Edition

- **Interactive Standalone Web App (`index.html`):** Zero setup or server required — just double-click and run in any browser.
- **25 Starter Objectives:** Story missions, side quests, and collectibles to test your dual-screen setup.
- **Retro Web Audio API Chime:** Real-time audio feedback upon completing objectives.
- **LocalStorage Memory:** Automatically saves your progress in your browser's persistent storage.
- **Instant Search:** Press `Ctrl + K` (or `Cmd + K`) to filter quests in real-time.

## 💻 Quickstart (Run Locally)

1. Clone or download this repo:
   ```bash
   git clone https://github.com/notionmaster001-max/vice-city-companion-starter.git
   ```
2. Double-click `index.html` to open in Chrome, Safari, Edge, or Firefox.
3. For mobile / iPad gaming: Transfer `index.html` to your device and tap **"Add to Home Screen"** for full-screen PWA immersion!
